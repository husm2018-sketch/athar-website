# Athar — موقع التطبيق / App website

موقع تعريفي + قانوني لتطبيق **أثر (Athar)**: رئيسية، خصوصية، شروط، إرشادات، ودعم.
ثنائي اللغة (عربي افتراضي RTL + إنجليزي) بثيم بنفسجي‑ذهبي يطابق شعار التطبيق، مع أنميشن خفيف.

> ملفات ثابتة فقط (no build step). الشعار `logo.png` هو أيقونة التطبيق نفسها.

## الملفات
| الملف | الوصف |
|------|-------|
| `index.html`      | الصفحة الرئيسية |
| `privacy.html`    | سياسة الخصوصية |
| `terms.html`      | شروط الاستخدام (تشمل بنود App Store + إخلاء مسؤولية صحي) |
| `guidelines.html` | الإرشادات — السلامة الصحية والمنهجية |
| `support.html`    | الدعم + خطوات حذف الحساب |
| `styles.css` · `script.js` · `logo.png` | الثيم والتفاعلات والشعار |

## الربط مع التطبيق
مدخلات الإعدادات داخل التطبيق تفتح هذه الصفحات مباشرة:
- سياسة الخصوصية → `privacy.html`
- الشروط والأحكام → `terms.html`
- السلامة الصحية والمنهجية → `guidelines.html`

## النشر (GitHub Pages)
الريبو: `athar-website`. عند تفعيل Pages على الفرع `main`:
- الرئيسية → `https://husm2018-sketch.github.io/athar-website/`
- الخصوصية → `…/privacy.html`  •  الدعم → `…/support.html`
