# موقع أثر القانوني والدعم

موقع عربي ثابت لتطبيق **أثر (Athar)**، مخصص للخصوصية والشروط وحذف الحساب والدعم وبيانات الصحة واللياقة. لا يحتوي على تسجيل دخول أو متجر أو لوحة تحكم أو بيانات تجريبية.

## المسارات

| المسار | الغرض |
| --- | --- |
| `/` | الصفحة الرئيسية وروابط الموقع |
| `/privacy-policy/` | سياسة الخصوصية |
| `/terms-of-service/` | شروط الاستخدام |
| `/delete-account/` | تجهيز طلب حذف الحساب عبر تطبيق البريد |
| `/support/` | التواصل والأسئلة الشائعة |
| `/health-data/` | توضيح الأذونات الصحية واللياقية |

الملفات القديمة `privacy.html` و`terms.html` و`guidelines.html` و`support.html` محفوظة كتحويلات توافقية إلى المسارات الجديدة.

## التعديل

- البريد مركزي في `script.js` داخل الثابت `SUPPORT_EMAIL`، وتبقى قيمة `athar.dev.app@gmail.com` ظاهرة في HTML إذا كان JavaScript معطلًا.
- نصوص الخصوصية والشروط موحدة مع النص العربي الموجود في تطبيق Flutter بتاريخ 17 أغسطس 2026، دون حقول قالب فارغة.
- تاريخ النص القانوني محفوظ كما هو في التطبيق؛ صفحات الصحة والحذف حُدّثت في 8 سبتمبر 2026.
- التصميم والأنماط مشتركة في `styles.css`، ولا توجد مكتبات خارجية أو خطوط ويب أو خطوة بناء.

نموذج حذف الحساب لا يتصل بواجهة حذف مباشرة. بعد التحقق من صحة البريد، يجهّز رسالة `mailto:` في تطبيق البريد لدى المستخدم، ويخبره بوضوح أن الطلب لم يُرسل أو يُنفذ تلقائيًا من الصفحة.

## المعاينة المحلية

```bash
cd /Users/hsm/Documents/Appweb

```

ثم افتح `http://localhost:8080/`.

## النشر

الموقع مرتبط بمستودع `husm2018-sketch/athar-website`. عناوين canonical وOpen Graph وsitemap تستخدم رابط GitHub Pages العامل المرتبط بالتطبيق: `https://husm2018-sketch.github.io/athar-website`. أي نطاق جديد يحتاج تأكيد ملكيته وضبط الاستضافة أولًا. الإصلاحات المحلية لا تصبح منشورة بمجرد حفظ الملفات.

قبل النشر العام:

1. راجع تطابق النصوص مع التطبيق عند أي تغيير في سلوكه أو بياناته.
2. تأكد أن `athar.dev.app@gmail.com` صندوق بريد عامل.
3. حدّث تاريخ النص عند تعديل السياسة نفسها.
4. اختبر جميع المسارات على عنوان الاستضافة الفعلي.
5. وحّد بريد الدعم والسياسة وروابط الصفحات داخل تطبيق Flutter مع النطاق المنشور؛ بناء الموقع وحده لا يغيّر روابط التطبيق الحالية.
6. اعتمد مصدرًا قانونيًا واحدًا وراجع تطابق نصوص الموقع مع سياسة الخصوصية والشروط المعروضة من التطبيق والخادم.
